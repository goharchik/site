# Просмотр моделей (MetroPack IR и другие)

`index.html` — готовый просмотрщик в одном файле, работает без интернета.

## Как пользоваться
1. Скопируй `viewer/index.html` в папку MetroPack (туда, где лежат `.obj`, `.mtl` и картинки), можно переименовать в `viewer.html`.
2. Открой его через сайт или локальный сервер — модели и окраски подхватятся сами.
3. Если открываешь просто как файл, страница попросит выбрать папку — выбери папку пака.

Поддерживаются `.obj` + `.mtl`, `.geo.json` (Bedrock) и `.bbmodel` (Blockbench).
Файлы одного вагона (`81-540.1bg` + `81-540.1fg`, `81-540.2f` + `81-540.2r`) открываются вместе как один вагон.
Сейчас показывается только серия 81-540 — это задаётся константой `ONLY_SERIES` в `src/app.js`.

Подпапки с картинками тех же имён (например `81-502_blue/`) показываются как «Окраска».

## Пересборка после правок в `src/`
```
cd viewer
npm i
npm run build
```
