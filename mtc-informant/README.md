# MTC Informant 1.2.0

Аддон-информатор для MTC (Minecraft Bedrock 1.26+).
Автор: нейросеть Claude. Создатель всех идей: Komarchik (TG: @komarchikoff).

- `MTC Informant BP/` — поведение: предмет и скрипт (`scripts/config.js` — разделы и звуки)
- `MTC Informant RP/` — ресурсы: иконки, звуки, переводы
- `GUIDE.md` — гайд для Telegram (RU + EN): установка, свой звук, свой раздел
- `addon-maker.html` — сборщик линий: из .ogg и иконки делает отдельное дополнение-раздел
- `python3 build.py` — проверка и сборка `dist/MTC_Informant_<версия>.mcaddon`
